      The DevOps Toolbox

      35+ essential tools across containers, CI/CD, GitOps, IaC, version control, observability, security, cloud and networking, with links to guides for each.

      Container & Orchestration

      Docker
      Container

      Docker

      Docker introduced the concept of packaging applications and their dependencies into lightweight, portable containers. A container includes everything needed to run: code, runtime, libraries, and configuration — running identically across development, staging, and production.

      • Dockerfile declarative image builds
      • Docker Compose for multi-container apps
      • Docker Hub registry with millions of images
      • Layer caching for fast, incremental builds
      13M+ Developers
      7M+ Images on Hub
      2013 Released
      K8s
      Orchestration

      Kubernetes

      Originally developed at Google and open-sourced in 2014, Kubernetes has become the de facto standard for container orchestration. It automates deployment, scaling, self-healing, and load balancing across clusters of machines.

      • Declarative configuration via YAML manifests
      • Horizontal pod autoscaling (HPA)
      • Rolling updates and rollbacks with zero downtime
      • Helm charts for templated application packaging
      96% Market adoption
      5.8K+ Contributors
      CNCF Graduated
      Helm
      Package Mgr

      Helm

      The package manager for Kubernetes. Helm uses Charts to define, install, and upgrade complex Kubernetes applications. Think of it as apt or brew but for Kubernetes manifests.

      • Reusable chart templates with values injection
      • Release management and rollback support
      • Artifact Hub with thousands of community charts

      More Container Tools

      Pod
      Container

      Podman

      A daemonless, rootless container engine with a Docker-compatible CLI (alias docker=podman mostly just works). It can generate Kubernetes YAML from running pods.

      • Rootless by default, so it is safer on shared hosts
      • No long-running daemon
      • podman generate kube / play kube
      kind
      Local K8s

      kind / minikube

      Run real Kubernetes clusters on your laptop. kind runs nodes as Docker containers, which makes it ideal for CI. minikube adds add-ons and a dashboard for learning.

      • Free, with no cloud account needed
      • Multi-node clusters in seconds
      • Perfect for testing Helm charts
      Project 05 →
      K9s
      CLI

      k9s

      A terminal UI for Kubernetes. Browse pods, tail logs, exec into containers, port-forward and delete resources with a few keystrokes, much faster than typing kubectl.

      • Live view of cluster resources
      • Logs, shell and describe in one place
      • Pulse and XRay views for health
      kubectl cheatsheet →

      CI/CD Pipelines

      Jenkins
      CI/CD

      Jenkins

      The most widely deployed open-source automation server. Jenkins orchestrates the build, test, and deploy pipeline using a Jenkinsfile (declarative or scripted pipeline), with 1,800+ community plugins.

      • Pipeline-as-Code via Jenkinsfile (Groovy DSL)
      • Distributed builds across agent nodes
      • Massive plugin ecosystem for any integration
      • Blue Ocean modern UI for pipeline visualisation
      1,800+ Plugins
      300K+ Installations
      GH Act
      CI/CD

      GitHub Actions

      Native CI/CD built into GitHub. Workflows are defined in .github/workflows/*.yml and triggered by push, pull request, schedule, or any GitHub event — with thousands of community actions in the Marketplace.

      • Matrix builds for cross-platform testing
      • Reusable workflows and composite actions
      • GitHub-hosted and self-hosted runners
      • OIDC-based cloud authentication
      GitLab
      CI/CD

      GitLab CI/CD

      GitLab offers a complete DevOps platform — from source control to monitoring — with built-in CI/CD defined in a .gitlab-ci.yml file. Particularly strong for self-hosted enterprise pipelines.

      • Multi-stage pipeline with DAG support
      • Auto DevOps for zero-config pipelines
      • Built-in container registry and package registry

      GitOps & Progressive Delivery

      Argo
      GitOps

      Argo CD

      A declarative GitOps controller for Kubernetes. Argo CD continuously syncs your cluster to manifests in Git, shows drift visually, and reverts manual changes.

      • Automated sync, prune and self-heal
      • ApplicationSets for many apps and clusters
      • SSO, RBAC and a rich web UI
      GitOps guide →
      Flux
      GitOps

      Flux CD

      A CNCF-graduated GitOps toolkit built from small controllers (source, kustomize, helm, image automation). Lightweight, CLI-first, and popular for multi-tenant platforms.

      • Native Helm and Kustomize controllers
      • Image update automation
      • Multi-tenancy with per-namespace sources
      Roll
      Delivery

      Argo Rollouts

      Progressive delivery for Kubernetes: canary and blue-green releases with traffic shifting, plus automated analysis against Prometheus metrics that aborts bad releases.

      • Canary steps with traffic weights
      • Automated metric analysis and rollback
      • Works with Ingress and service meshes

      Infrastructure as Code

      Terraform
      IaC

      Terraform

      HashiCorp's Terraform lets you define cloud infrastructure using the HCL declarative language. A single configuration can provision resources across AWS, Azure, GCP, and hundreds of other providers via the Terraform Registry.

      • Plan → Apply workflow with change previews
      • State management with remote backends (S3, Terraform Cloud)
      • Modular, reusable infrastructure components
      • 1,000+ providers in the Terraform Registry
      1,000+ Providers
      OpenTofu Open-source fork
      Ansible
      Config Mgmt

      Ansible

      Red Hat's Ansible is an agentless configuration management tool. Using Playbooks written in YAML, Ansible can configure systems, deploy software, and orchestrate complex multi-tier deployments — no agent installation required.

      • Agentless — uses SSH or WinRM
      • Idempotent playbooks ensure desired state
      • Ansible Galaxy — community role library
      • AWX / AAP for enterprise automation at scale

      More IaC Tools

      Tofu
      IaC

      OpenTofu

      The open-source, Linux Foundation fork of Terraform, created after Terraform's licence change. It is a drop-in replacement for most configurations and adds features like state encryption.

      • MPL-licensed and community-governed
      • Compatible with Terraform providers and modules
      • Built-in client-side state encryption
      Pulumi
      IaC

      Pulumi

      Infrastructure as code in general-purpose languages: TypeScript, Python, Go, C# and Java. Use loops, functions, packages and unit tests instead of a DSL.

      • Real languages, IDEs and testing
      • Same cloud coverage as Terraform
      • Pulumi ESC for secrets and config
      Packer
      Images

      Packer

      Builds identical machine images (AMIs, Azure images, VM templates) from a single config. Bake software into "golden images" so servers boot ready to run, instead of configuring them at boot.

      • Immutable infrastructure
      • Provision with shell or Ansible
      • Multi-cloud images from one template

      Version Control

      Git
      VCS

      Git

      The distributed version control system created by Linus Torvalds in 2005. Git enables branching strategies like Git Flow, trunk-based development, and GitHub Flow — the foundation of every modern DevOps pipeline.

      • Branching and merging workflows
      • Signed commits and tags
      • Hooks for pre-commit automation
      GH
      Platform

      GitHub

      The world's largest code hosting platform with 100M+ developers. GitHub extends Git with pull requests, code review, issue tracking, project boards, Actions CI/CD, and GitHub Copilot AI assistance.

      • Pull request review workflows
      • Branch protection rules
      • GHAS security scanning
      GL
      Platform

      GitLab

      A complete DevOps platform in a single application. GitLab offers source control, CI/CD, security scanning, package registry, and monitoring in one self-hostable or SaaS solution — ideal for regulated environments.

      • Single-application DevOps
      • Self-hosted EE option
      • Compliance pipelines

      Monitoring & Observability

      Prom
      Metrics

      Prometheus

      The leading open-source monitoring system and time-series database. Prometheus scrapes metrics via HTTP, stores them with a powerful query language (PromQL), and fires alerts via Alertmanager.

      • Pull-based metric scraping
      • PromQL query language
      • Kubernetes-native service discovery
      Grafana
      Dashboards

      Grafana

      The open-source observability and data visualisation platform. Grafana connects to dozens of data sources — Prometheus, Loki, Tempo, Elasticsearch — and renders beautiful, actionable dashboards.

      • Multi-data-source dashboards
      • Alerting and on-call routing
      • Grafana LGTM observability stack
      HashiCorp Vault
      Security

      HashiCorp Vault

      Centralised secrets management and data protection. Vault stores API keys, passwords, certificates, and tokens — with dynamic secret generation, lease renewal, and revocation for zero long-lived credentials.

      • Dynamic secrets with automatic rotation
      • PKI and certificate authority
      • Fine-grained policies via HCL

      More Observability Tools

      OTel
      Standard

      OpenTelemetry

      The vendor-neutral CNCF standard for traces, metrics and logs. Instrument once with OTel SDKs, then send the data anywhere (Prometheus, Tempo, Jaeger, Datadog) through the OTel Collector.

      • One instrumentation for all backends
      • Auto-instrumentation for major languages
      • Collector for processing and routing
      Loki
      Logs

      Grafana Loki

      Log aggregation "like Prometheus, but for logs". It indexes only labels, not full text, which makes it cheap to run. Query it with LogQL and correlate with metrics in Grafana.

      • Low-cost label-based indexing
      • LogQL queries and log-based alerts
      • Ships logs via Grafana Alloy or Promtail
      Tempo
      Traces

      Jaeger / Tempo

      Distributed tracing backends. A trace follows one request across every service it touches, showing exactly which hop is slow or failing.

      • Find the slow span in a request
      • Service dependency graphs
      • Jump from traces to logs and metrics

      Security & DevSecOps

      Trivy
      Scanner

      Trivy

      An all-in-one open-source scanner: container images, filesystems, Git repos, IaC misconfigurations, Kubernetes clusters, secrets and SBOMs. Easy to drop into any CI pipeline.

      • Image CVE and IaC misconfiguration scans
      • SBOM generation (SPDX, CycloneDX)
      • Fail builds on chosen severities
      DevSecOps guide →
      Sonar
      Code quality

      SonarQube

      Static analysis for code quality and security (SAST) across 30+ languages. Quality gates block merges when coverage, bugs or vulnerabilities fall outside agreed thresholds.

      • Bugs, code smells and vulnerabilities
      • Quality gates on pull requests
      • Coverage and duplication tracking
      Kyverno
      Policy

      Kyverno / OPA

      Policy engines for Kubernetes admission control. Block privileged pods, enforce labels and limits, and require signed images. Kyverno policies are YAML; OPA Gatekeeper uses Rego.

      • Validate, mutate and generate resources
      • Verify Cosign image signatures
      • Audit reports for existing workloads

      Cloud Platforms

      AWS
      Cloud

      Amazon Web Services

      The largest cloud provider. Core DevOps services: IAM, VPC, EC2, EKS/ECS, Lambda, S3, RDS, CloudWatch, plus the richest ecosystem of Terraform modules and tutorials.

      • EKS for managed Kubernetes
      • IAM roles and OIDC for keyless CI
      • Broadest service catalogue
      AWS guide →
      Azure
      Cloud

      Microsoft Azure

      Strong in enterprises already using Microsoft 365 and Active Directory (Entra ID). AKS, Azure DevOps Pipelines and Bicep/ARM templates are its DevOps building blocks.

      • AKS managed Kubernetes
      • Entra ID integration
      • Azure DevOps and GitHub (same parent company)
      GCP
      Cloud

      Google Cloud

      The birthplace of Kubernetes and SRE. GKE is widely considered the most polished managed Kubernetes; BigQuery and Vertex AI lead in data and ML.

      • GKE (Standard and Autopilot)
      • Cloud Run for serverless containers
      • Strong data and ML platform

      Networking & Service Mesh

      Nginx
      Proxy

      Nginx

      High-performance web server, reverse proxy and load balancer, and the engine behind the popular ingress-nginx Kubernetes controller. You will meet its config files everywhere.

      • Reverse proxy and TLS termination
      • Load balancing and caching
      • ingress-nginx for Kubernetes
      Networking guide →
      Istio
      Service mesh

      Istio / Linkerd

      Service meshes add mTLS encryption, retries, timeouts, traffic splitting and golden-signal metrics between services, without changing application code.

      • Automatic mTLS between services
      • Traffic shifting for canaries
      • Uniform service-to-service telemetry
      Cilium
      CNI

      Cilium

      An eBPF-powered Kubernetes networking (CNI) plugin offering fast networking, NetworkPolicies, observability (Hubble) and even a sidecar-free service mesh.

      • eBPF data plane, can replace kube-proxy
      • L3–L7 network policies
      • Hubble flow visibility
